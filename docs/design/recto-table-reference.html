Table styles for Recto

Three treatments of the same table. Hover a row to see its grip, click a row's grip to select it, click a header to open the column menu.

A · Quietrecommended

No vertical lines, no fills. Hairline rows, a muted header, numbers right-aligned. Reads like part of the note, not a spreadsheet pasted into it.

B · Card

A rounded box with a hairline edge and a tinted header. Clearly an object; good when a note has several tables.

C · Grid

Close to what Recto has now, cleaned up: lighter lines, subtle stripes. Most spreadsheet-like, heaviest on the page.
